# Valyria Web App

نسخهٔ وب مستقل والریا برای سیزن آینده، بدون نیاز به تلگرام برای ثبت‌نام یا ورود.

- حساب با نام کاربری و رمز، کد بازیابی، نشست امن و تنظیمات حساب.
- صندوق اعلان داخلی با جست‌وجو، فیلتر، خواندن، بایگانی و بازگرداندن.
- وب‌اپ قابل نصب، آیکن، فایل‌های محلی و صفحهٔ قطع اتصال.
- تمام مکانیک‌های بازی، پنل مدیریت و نقشهٔ نسخهٔ مبنا حفظ شده‌اند.
- دیتابیس و استقرار مستقل؛ اطلاعات بازیکنان نسخهٔ فعال منتقل نشده‌اند.

**این شاخه را روی محیط نسخهٔ تلگرامی فعلی منتشر نکنید.**

راهنمای نصب، ایجاد ادمین اولیه، بازیابی رمز و نگهداری دو نسخه: [راهنمای نسخهٔ وب](docs/WEB_APP_FA.md).

```sh
cp .env.example .env
# Set APP_HOST and PUBLIC_APP_ORIGIN for the new server.
docker compose up -d --build
docker compose exec backend python -m web_auth bootstrap-admin
```

نام نصب‌شده روی گوشی: **Valyria Web App**. برای انتشار عمومی آدرس HTTPS معتبر لازم است. صندوق داخل اپ مستقل است؛ اعلان هنگام بسته بودن برنامه در این نسخه تضمین نمی‌شود.
