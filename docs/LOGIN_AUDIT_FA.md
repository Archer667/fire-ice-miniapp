# هشدار ورود از IP مشترک

ورود معتبر از مسیر `/api/players/me` در Vercel به تابع `api/login.js` می‌رود.
تابع، IP دریافت‌شده از Vercel را همراه زمان و هدر احراز هویت امضا می‌کند.
سرور تنها امضای معتبر با عمر حداکثر ۶۰ ثانیه را می‌پذیرد؛ هدرهای عادی
X-Forwarded-For و IP واسط برای این قابلیت استفاده نمی‌شوند.

متغیر محرمانهٔ `LOGIN_AUDIT_SECRET` باید در محیط backend و محیط‌های
Production و Preview پروژهٔ Vercel دقیقاً یکسان باشد. کلید نباید با پیشوند
VITE_ تعریف شود یا وارد مخزن شود. نبود کلید مانع ورود به بازی نمی‌شود،
اما ثبت IP غیرفعال می‌ماند. پس از تنظیم متغیر، انتشار مجدد Vercel لازم است.

هر حساب ثبت‌شده و IP یک رکورد آخرین ورود دارد. دو حساب با IP یکسان در
۲۴ ساعت اخیر باعث ارسال نام و شناسهٔ دو بازیکن به OWNER_ID می‌شوند.
هشدار هر جفت حساب در ۲۴ ساعت فقط یک بار صادر می‌شود. رکوردهای بلااستفاده
بعد از ۷ روز با TTL مونگو حذف می‌شوند. داده‌ای از قبل از فعال‌سازی بازیابی نمی‌شود.
پیام با سازوکار فعلی ارسال بات فرستاده می‌شود؛ تحویل در صورت مسدود بودن بات
یا اختلال تلگرام تضمین‌شده نیست. هیچ مسدودسازی خودکاری انجام نمی‌شود.

IP مشترک می‌تواند مربوط به VPN یا اینترنت مشترک باشد و اثبات چنداکانتی نیست.
این ثبت فقط درخواست‌های عبوری از تابع Vercel را پوشش می‌دهد؛ ورود مستقیم
به backend بدون امضای معتبر وارد این گزارش نمی‌شود.

تست‌ها فقط روی دیتابیس جداگانهٔ `valyria_login_test` اجرا می‌شوند؛ ارسال بات
در تست شبیه‌سازی می‌شود و پیام واقعی به ادمین نمی‌رود.
